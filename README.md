## Introduction  
The **AI content creation landscape** is growing rapidly, with startups offering tools for video, image, music, and text creation. Whether you're an solopreneur, developer, or creator, this directory showcases companies pushing the boundaries of content creation with AI.

## Pricing Legend
- `Free` - No cost to use basic features
- `Freemium` - Free tier with paid premium features
- `Paid` - Paid service with possible trial
- `Open Source` - Source code freely available
- `Proprietary` - Closed source software
- `Unreleased` - Not yet available to public

## Contributing  
We welcome contributions! 🚀  

To add a startup:  
1. Fork this repository
2. Add the startup (alphabetically) to the appropriate category following the format:
   ```markdown
   - **[Name](url)** – Brief description. `Pricing` `License Type`
   ```
3. Submit a pull request

Please include:  
- Name and website URL
- Brief description (1–2 sentences)
- Pricing model
- License type (Open Source/Proprietary)
